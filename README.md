# ZNS - Simple DoH server in Go

## 安装

```bash
go install github.com/taoso/zns/cmd/zns@latest
```

## 运行

```bash
zns -c /etc/zns/zns.toml
```

配置文件格式参考 [zns.toml](./misc/etc/zns.toml)
